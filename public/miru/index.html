Media server telemetry

miru

Lightweight, security-hardened media server telemetry, live stream monitor, playback history tracker, and library analytics. Built with Kotlin, Ktor, Arrow-kt, and a SvelteKit PWA in a 68.0 MiB Distroless container.

docker run -d --name miru -p 8080:8080 -e AUTH_SESSION_SECRET="$(openssl rand -base64 48)" -e MIRU_ENCRYPTION_KEY="$(openssl rand -base64 48)" -v miru-data:/data ghcr.io/hononeko/miru:latest

Installable SvelteKit PWA, dark and light

Live sessions, history, user scoping, and library insights adapt cleanly to mobile screens in both dark and light themes.

Everything happening on Plex, in one place

Miru connects straight to your Plex server to track live streams, playback history, and library health — packaged as a single container with the web app built in.

Live streams as they happen

Connects to Plex's WebSocket feed and pushes stream starts, pauses, and stops straight to your browser over SSE, with automatic polling fallback if the socket drops.

History, stats & Tautulli import

Tracks every play with resume-window merging, watch thresholds, and year-in-review summaries. Bringing existing history? Import your Tautulli database in seconds.

Library codecs & stale storage

Inspect movies and TV libraries by resolution, video and audio codec, growth over time, and unwatched files taking up space.

Scoped accounts & single sign-on

Sign in with local accounts, OIDC single sign-on, or API keys. Link regular users to their Plex profiles so they only see their own history and shared libraries.

SQLite out of the box, PostgreSQL when you want it

Starts up on an embedded SQLite file with no extra services, or switches to PostgreSQL with a single DB_ENGINE=postgres setting.

One small, self-contained image

The API and installable PWA ship together in a 68.0 MiB Distroless container, complete with /healthz, /readyz, and a live OpenAPI spec.

Hardened by default

Plex tokens, sessions, and outbound fetches stay behind a single typed Ktor boundary. Every control is source-verified in docs/security.md.

Auth, rate limits & section RBAC

Argon2id hashing with a 4-way concurrency cap, bounded per-IP and per-account rate limiting, proxy-aware Secure HttpOnly cookies, asymmetric PKCE S256 OIDC, and fail-closed Plex library-section RBAC across metadata, artwork, and SSE.

CSP, encrypted secrets & SSRF defense

Global security headers with startup SHA-256 CSP script hashes, AES-256-GCM encrypted Plex tokens that never reach the browser, DNS public-IP validation with socket-pinned HTTPS avatar fetches, XXE-disabled XML parsers, and read-only 256 MiB capped SQLite imports.

Distroless & supply-chain gates

Digest-pinned shell-less Distroless + 14-module jlink runtime as UID 10001 with --read-only and /tmp:noexec, Kubernetes restricted PSS manifests, blocking Trivy CVE scans, CodeQL, and GHCR Artifact Attestations.

Quick start

Run the multi-arch container image with Docker Compose and SQLite, then open http://localhost:8080, create the first admin account and connect Plex from Admin. For Kubernetes, start from the example Kustomize manifests in docs/k8s/. Every setting is listed in the environment variable reference.

$ mkdir miru && cd miru
$ curl -fsSLO https://raw.githubusercontent.com/hononeko/miru/main/docs/docker-compose.yml
$ cat > .env <<EOF
AUTH_SESSION_SECRET=$(openssl rand -base64 48)
MIRU_ENCRYPTION_KEY=$(openssl rand -base64 48)
EOF
$ docker compose up -d   # SQLite on a named volume; see the file for PostgreSQL

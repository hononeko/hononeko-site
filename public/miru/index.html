Media server telemetry

miru

Lightweight media server telemetry, live stream monitor, playback history tracker, and library analytics. Built with Kotlin, Ktor, Arrow-kt, and a SvelteKit PWA backed by SQLite or PostgreSQL.

docker run -d -p 8080:8080 -e PLEX_URL=http://plex:32400 -e PLEX_TOKEN=your-token -e AUTH_MODE=none -v miru-data:/data ghcr.io/hononeko/miru:latest
View on GitHub Kubernetes guide

Installable SvelteKit PWA, dark and light

Live sessions, history, user scoping, and library insights adapt cleanly to mobile screens in both dark and light themes.

Built for Plex, typed end to end

A Kotlin 2.4 / Ktor 3 API with Arrow-kt typed errors and an OpenAPI 3.1 contract, bundling a static SvelteKit 2 + Svelte 5 frontend into one container.

Real-time Plex monitoring

Listens on Plex's WebSocket notification stream with debounced updates and exponential backoff, paired with a fallback polling reconciler and SSE live push.

Playback history & RBAC scoping

Records play sessions with resume-window merging and watch thresholds. Link USER accounts to specific Plex users to scope all views and history.

Library codec & growth analytics

Break down library sections by video codec, resolution, audio format, and item growth over time across movies, TV shows, and episodes.

OIDC, local & API key auth

Run with local HMAC-SHA256 session cookies, OIDC single sign-on (or hybrid mode), and SHA-256 hashed miru_... API keys for automation.

SQLite & PostgreSQL parity

Start immediately with embedded SQLite, or point DB_ENGINE=postgres at PostgreSQL. Both engines share Flyway migrations and Exposed repositories.

Single container, OpenAPI 3.1

Ktor serves the built SvelteKit PWA from /opt/miru/static alongside /healthz, /readyz, and /api/v1/openapi.yaml.

Quick start

Run the multi-arch container image with SQLite, or deploy to Kubernetes using the Kustomize blueprint in k8s/.

$ docker run -d --name miru -p 8080:8080 \
    -e PLEX_URL=http://host.docker.internal:32400 \
    -e PLEX_TOKEN=your-plex-token \
    -e AUTH_SESSION_SECRET="$(openssl rand -hex 32)" \
    -e MIRU_ADMIN_USERNAME=admin \
    -e MIRU_ADMIN_PASSWORD=choose-a-strong-password \
    -v miru-data:/data \
    ghcr.io/hononeko/miru:latest
$ curl -fsS http://localhost:8080/readyz   # readiness check + OpenAPI at /api/v1/openapi.yaml

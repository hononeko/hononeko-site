Renovate orchestrator

koshin

Renovate on Kubernetes, run when there's work to do. A proxy coalesces GitHub and GitLab webhooks and starts worker Jobs on demand, so nothing runs while the queue is empty, and no autoscaler is needed.

helm install koshin oci://ghcr.io/hononeko/charts/koshin -n koshin --create-namespace --set proxy.existingSecret=koshin-proxy --set worker.existingSecret=koshin-worker
Install with Helm How it works

Renovate when there's work, and only then

A stateless proxy and workers on NATS JetStream and Valkey. Workers run back to back while there are jobs, and exit once idle.

Coalesced webhooks

A webhook for a repository that's already queued is dropped. One that arrives mid-run marks the repository for a single follow-up run.

Scale to zero

The proxy starts workers as Kubernetes Jobs from a PodTemplate. With an empty queue no worker runs, and there's no autoscaler to install.

One App, many tenants

Serve many accounts from one public GitHub App, with an allow-list of the accounts it runs for. GitLab works with a token.

Rate limits per credential

Runs are capped per App installation or platform token, and only the scope that hit a rate limit backs off. Everyone else keeps going.

Encrypted registry credentials

Tenants keep private registry secrets in their own Renovate config, encrypted with koshin's key and decryptable only for their repositories.

Clean between runs

Renovate runs in a separate, secret-free container from the upstream image. Caches are emptied, leftover processes killed and tokens scrubbed from logs.

Quick start

Kubernetes 1.30+, with no operator or autoscaler. The minimal profile runs one NATS and Valkey; ha survives losing a node.

$ kubectl create namespace koshin
$ kubectl -n koshin create secret generic koshin-proxy \
    --from-literal=GITHUB_WEBHOOK_SECRET=... \
    --from-literal=INTERNAL_TRIGGER_TOKEN="$(openssl rand -hex 24)"
$ kubectl -n koshin create secret generic koshin-worker --from-literal=GITHUB_TOKEN=...
$ helm install koshin oci://ghcr.io/hononeko/charts/koshin -n koshin \
    --set proxy.existingSecret=koshin-proxy \
    --set worker.existingSecret=koshin-worker \
    --set 'proxy.sweepRepositories={github:my-org/my-repo}'   # re-checked every 6 hours

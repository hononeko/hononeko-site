Git accounts per folder

doppel

Every repo commits as the right Git account. Repos under ~/projects/work commit, push and sign as your work identity; everything else stays personal. You never switch anything by hand.

go install github.com/vehkiya/doppel@latest

Plain Git config, applied by Git

doppel doesn't wrap git and doesn't need to be running. It writes the config, and Git does the rest.

Accounts per folder

Each account has a commit identity, an SSH key for pushing, an optional signing key, and the folders it applies to. The most specific folder wins.

The right key, every time

Each account pushes with its own key and IdentitiesOnly=yes, so ssh-agent can't log you in to GitHub as the wrong account.

Signatures that verify

SSH signing per account, with a managed block in allowed_signers so git log --show-signature shows a good signature.

Keys handled for you

Pick a key or generate one, or use an agent such as 1Password or Bitwarden. doppel upload adds them to the right GitHub user.

It explains itself

doppel whoami says which account applies and why, test logs in and signs, and doctor finds what could go wrong.

Careful with your files

--dry-run shows every change as a diff, every write is atomic with a backup, and doppel uninstall takes it all back out.

Quick start

Linux and macOS. Needs Git 2.34+ and OpenSSH 8.2+; gh is optional, for uploads.

$ doppel add            # a wizard: identity, hosts, folders, keys, signing
$ doppel                # the account browser
$ doppel whoami         # which account applies here, and why
$ doppel test           # log in to each host and sign a test message
$ doppel upload work    # add work's keys to its GitHub user

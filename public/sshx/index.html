SSH host manager

sshx

Your SSH hosts, without hand-editing ~/.ssh/config. Search and connect from a terminal UI, add hosts with a guided wizard, and keep every comment and directive you wrote.

go install github.com/hononeko/sshx@latest
Download a release Other ways to install

Everything ssh knows, one keypress away

sshx reads the config you already have, includes and all, and changes only what you ask it to.

Search and connect

Fuzzy-filter every alias, hostname and note. The inspector shows the target, port, key and jump host, and Enter connects.

A wizard for new hosts

sshx add walks you through a host: pick a key or generate an Ed25519 one, preview the config block, then copy the key to the server.

Edits in place

Only the directives you change are rewritten. Comments, wildcard patterns and directives sshx doesn't manage stay where they were.

Safe writes

Atomic writes with 0600 permissions, a hidden backup of the previous file, and symlinked dotfiles written through, not replaced.

Straight from the shell

sshx prod uptime, sshx ls --json, and tab completion for bash, zsh and fish, with your most recent hosts first.

Signed updates

sshx update only installs a release whose checksums are signed with the sshx release key.

Quick start

A single static binary for macOS, Linux and Windows. No runtime dependencies.

$ sshx                                  # browse your hosts
$ sshx add admin@10.0.0.5:2202 backup   # add one, with the wizard filled in
$ sshx backup                           # connect
$ sshx backup uptime                    # run a command; ssh's exit code passes through
$ source <(sshx completion zsh)         # tab-complete your hosts
